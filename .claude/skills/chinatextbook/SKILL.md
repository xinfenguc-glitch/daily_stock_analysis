# ChinaTextbook 全库检索与下载

把自然语言的教材需求变成 `TapXWorld/ChinaTextbook` 里的具体文件并下载。
与只覆盖主科的工具不同，本技能覆盖上游仓库的**全部 7 个顶层目录**。

## 覆盖范围

| 顶层目录 | 内容 |
| --- | --- |
| `小学` | 语文、数学、英语、科学、音乐、美术、艺术、体育与健康、道德与法治、语文·书法练习指导 |
| `初中` | 上述 + 物理、化学、生物学、历史、地理、地理图册、人文地理、俄语、日语 |
| `高中` | 上述 + 思想政治、信息技术、通用技术 |
| `小学（五•四学制）` | 一~五年级平行体系 |
| `初中（五•四学制）` | **六~九年级**平行体系 |
| `大学` | 高等数学、线性代数、离散数学、概率论（仅数学类，约 19 册） |
| `学数学最重要的刷习题在这里` | 各省市中考数学真题与答案 |

完整清单见 `references/catalog.md`；机器可读版本见 `assets/taxonomy.json`。

## 工作流

1. 解析需求：学段、学制、年级、学科、册别/模块、版本、省市、材料类型。
2. **先检索，后下载**。
3. 候选明确时下载；不明确时列出候选让用户选。
4. 返回本地路径、上游路径、来源 URL、拆分件状态与排序理由。

```bash
S="${CLAUDE_SKILL_DIR:-.}/scripts/chinatextbook.py"

python3 "$S" search "初中 八年级 物理 上册 人教版" --explain
python3 "$S" search "鲁教版 五四制 六年级 数学 上册" --explain
python3 "$S" download "高中 通用技术 必修 技术与设计1" --pick 1
python3 "$S" download "小学 三年级 语文 上册" --auto
```

## 关键语义（容易出错的地方）

### 五•四学制是独立平行体系

**六年级在五•四学制里属于初中**，在六•三学制里属于小学。这是最容易出错的一点。
用户提到 `五四制`、`五·四学制`、`54 学制` 时，必须走 `小学（五•四学制）` / `初中（五•四学制）` 目录。
脚本已内置该映射并会在 `--explain` 中说明；不要手工按六•三学制推断。

### 版本目录有长短两种写法

同一版本可能是 `人教版`，也可能是 `人教版-人民教育出版社`，还可能带主编或分册标记，
例如 `人教版（A版）（主编：章建跃&李增沪）-人民教育出版社`。
检索时用短名（`人教版`）即可，脚本会匹配到长目录。

### 音乐分五线谱 / 简谱

`人音版（五线谱）` 与 `人音版（简谱）` 是不同教材。用户没说时应询问或同时列出。

### 英语分起点

`（一年级起点）` 与 `（三年级起点）` 是不同教材，直接影响可用年级。

### 地理图册是独立学科

`地理图册` 与 `地理` 是不同目录，且图册版本常写成 `配套人教版`、`配套湘教版`。

### 拆分文件

上游有两种拆分约定，脚本都会自动还原并按**数值序**合并（分片可到 `.pdf.11`，
字典序会把 `.10` 排到 `.2` 前面，必须数值排序）：

- `X.pdf_merge_folder/X.pdf.N`
- 同级兄弟文件 `X.pdf.N`

分片编号不连续时脚本会拒绝合并而不是产出损坏文件。

### 教师用书与答案默认降权

用户没主动要 `教师用书`、`习题全解`、`答案` 时，这些会被降权，避免把教辅当教材返回。

## 索引来源

优先级：本地缓存（24 小时）→ GitHub Trees API → 技能自带快照 `assets/index.json.gz`。

API 不可达（网络受限、限流、代理拦截 `api.github.com`）时自动回退到内置快照并在 stderr 提示。
内置快照是**文件路径清单**，不含教材内容。用 `--refresh` 强制拉取最新目录，
`--offline` 强制只用快照。设置 `GITHUB_TOKEN` 可提高 API 限额。

## 边界

- 只下载 GitHub 上公开可访问的文件，不绕过登录、付费、版权或访问限制。
- 教材内容版权属于原出版社；本技能只做检索与下载，不复制、转述或再分发教材正文。
- 省份版本偏好只是**排序权重**，不是官方选用结论。上游按学段/学科/版本组织，不按省份组织；
  同一省份不同地市、区县、学校、学年可能用不同版本。需要确定版本时应以学校书单为准。
- 大学部分只有数学类约 19 册，不是完整本科教材库；不要暗示覆盖全学科。
- 上游没有精确版本时，列出最接近的候选，不要把近似版本说成精确命中
  （例如用户要第六版而仓库只有第七版）。
- 年级、学科或册别不明确且候选接近时，不自动下载，交给用户确认。
